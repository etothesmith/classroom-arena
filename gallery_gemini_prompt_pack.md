# Classroom Arena — Gallery Walk Source & Gemini Prompt Pack (v2)

Each prompt now uses an art style that matches its era (1860s wood engraving → 1890s Puck color → 1910s ink → 1930s crayon → 1940s posters → 1960s ink wash) and a scene tied to the station's benchmark. Save each Gemini image with the file name shown so it is easy to upload to the right station.

Every station is a historical document or political cartoon. For each one:
- **Find the original** — the Library of Congress search link for the public-domain scan. Download it and upload it in Teacher Studio → Gallery Walk Manager → "Original scan".
- **Gemini prompt** — makes an ORIGINAL teaching illustration on the same idea (not a copy of the historical cartoon). Upload it as "Gemini art"; students see it labeled as a teaching illustration, not a historical artifact.
